# saeDevWeb_RENARD_MEON_MEDJAHED_BAMONDE
SAE de développement Web où on programme une application appelée Touiteur.app dans laquelle un utilisateur peut créer des Touites (un texte associé au nom de l'utilisateur) visibles par d'autre utilisateurs. Un utilisateur peut également suivre d'autre utilisateurs et des Tags représentés par # dans le texte des Touites
